# SchoolOye docs

| Doc | Where | Use it for |
|---|---|---|
| **Master Document** | Claude Docs (outside the repo) | Why, for whom, positioning, GTM, phases, feature catalogue, KPIs |
| **Decisions Register** | `decisions.md` | What's decided — wins every conflict |
| **Developer Spec** | `spec/` (start at `spec/README.md`) | How the platform works and what to build, one file per feature |
| **Guidelines** | `guidelines/seo-geo.md`, `guidelines/content-and-trust.md`, `guidelines/design.md` | Rules every page follows |
| **Status** | `screen-map.md`, `design-gaps.md`, `page-enrichment-backlog.md` | What's built, what's design-pending, parked ideas |
| **Ops runbooks** | `ops/deploy.md`, `ops/call-script.md`, `ops/data-retention.md` | Running the platform |
| **Archive** | `archive/` | Snapshots and superseded docs — never cited as rules |

**Authority order:** Decisions Register → Developer Spec → Guidelines → Master Document → archive.
Repo root `CLAUDE.md` is the short rulebook that Claude Code loads every session; it points here.
