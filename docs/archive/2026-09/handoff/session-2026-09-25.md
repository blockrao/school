## Environment / process notes for whoever resumes

- This session had a recurring issue with orphaned `next start` background
  processes piling up on port 3000 across many local test cycles. Before
  starting a new local server, check `lsof -nP -iTCP:3000 -sTCP:LISTEN` and
  kill anything stale first, or the new build won't actually be what gets
  tested.
- `pnpm build` regenerates Next's route types — always run it once after adding
  a brand-new route before `pnpm typecheck` will recognize that route's
  `PageProps<...>` type.
- Destructive/personal-data-policy SQL needs the exact SQL shown in chat and an
  explicit "yes" tied to that specific message — the auto-mode permission
  classifier enforces this literally now (a vague or earlier-in-conversation
  approval isn't accepted), see item 2 above for what that looked like in
  practice.
